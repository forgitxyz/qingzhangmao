## 二、绕不开的两件行政手续（需要你自己办）

国内商店 2023 年后普遍强制以下两项，缺了无法提审：

1. **软件著作权证书（软著）或电子版权认证**
   - 中国版权保护中心登记，个人可办，费用约 250～300 元，周期 1～2 个月
   - 加急电子认证（如「电子版权认证证书」）约 3～7 个工作日，各商店均认可
   - 证书上的软件名称建议：**清帐猫债务管理软件 V1.0.0**（全称必须含「软件」二字和版本号）
2. **工信部 ICP/App 备案**
   - 在你提交的第一个商店（建议华为或小米）后台发起，商店代为转交
   - 需要身份证 + 手机号 + 应用包名 `com.qingzhangmao.app`
   - 备案周期约 1～3 周

另需注册开发者账号（个人均可）：

| 商店 | 个人开发者 | 备注 |
|---|---|---|
| 华为应用市场 | 可，免费 | 审核最严、量最大，建议首发 |
| 小米应用商店 | 可，免费 | — |
| OPPO 软件商店 | 可，免费 | — |
| vivo 应用商店 | 可，免费 | — |
| 应用宝 | 可，免费 | 需软著 |
| TapTap / 酷安 | 酷安个人可发 | 酷安对独立开发者最友好，可先上 |

## 三、商店文案（直接复制）

**应用名**：清帐猫

**一句话简介**（≤20 字）：完全离线的债务管理与还款计划工具

**应用介绍**：

> 欠了几个平台，每月要还多少、生活费还剩多少，总也算不清？
> 清帐猫把这一切摆在一张表上。
>
> 【债务台账】每个平台一张卡片：本金、剩余欠款、月供、利率、还款日，协商结果原样留档
> 【清帐计划】雪球法/雪崩法模拟，算出每一笔债哪个月结清、总共还多少利息
> 【生活刚需】房租、水电、物业、猫粮、饭钱，先保生活再谈还款
> 【缺口预警】收入盖不住月供时，红字提醒并告诉你先跟哪一家谈
> 【还款打卡】记一笔自动扣减欠款，还清自动点亮
>
> 🔒 完全离线：不联网、不注册、不收集任何数据，记录只存在你手机里
> 🔒 每日自动备份，卸载前导出一份 JSON 即可迁移
>
> 一笔一笔还清，心里有数。

**关键词**：记账 债务 还款 上岸 协商 逾期 信用卡 网贷 台账

**分类**：财务 / 理财记账

2. **软著申请材料**：源代码前后各 30 页 PDF + 说明文档，直接用本仓库代码导出即可

## 五、GitHub 发布流程（不涉store审核，先上线）

1. 在 GitHub 新建空仓库（如 `qingzhangmao`），不要初始化 README
2. 本地推送：
   ```bash
   cd qingzhangmao
   git remote add origin https://github.com/<你的用户名>/qingzhangmao.git
   git push -u origin main
   ```
3. CI 会自动构建 Debug APK（Actions 页面可下载）
4. 发正式版：
   ```bash
   git tag v1.0.0 && git push origin v1.0.0
   ```
   Actions 会自动构建并把 APK 和 macOS 包挂到 Releases

> 注意：CI 上目前出的是 Debug 签名 APK。要在 Actions 出正式签名包，
> 需把 `清帐猫-release.keystore` 转 base64 存到仓库 Secrets（`KEYSTORE_BASE64`、
> `KEYSTORE_PASSWORD`、`KEY_ALIAS`、`KEY_PASSWORD`），工作流已支持，收到即自动签名。
